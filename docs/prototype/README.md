# Prototipos

Material previo al desarrollo, conservado como historia del proyecto.

- **`Mocks/`** — Maquetas de la interfaz organizadas por las tareas del estudio
  de usabilidad (*think aloud*): acceso y panel, flujo de pago y listado de
  monedas.
- **`JavaScript/`** — Primera prueba de concepto en HTML y JavaScript, anterior
  a la elección de React.

El prototipo abandonado de Create React App (`React/`) se ha eliminado: no
compartía código con la aplicación y arrastraba 4,6 MB de JSON duplicados que ya
existían en el proyecto principal.
